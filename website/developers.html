Developers

Open source. Real stack. No lock-in.

NeoApps turns a MySQL schema and a UI config into a full app. Two years open source, built on 15 years of ERP work.

.NET 10 API

Generated controllers, repositories, JWT auth and Swagger.

React admin UI

React 19 and MUI, driven by schema.json and ui.config.json.

MySQL, Redis, RabbitMQ

Background jobs, approvals and events, out of the box.

MCP server and CLI

Every operation as a tool for Claude, ChatGPT, Codex and others.

Run it locally

One command to install.

Needs Docker. Registers the MCP server with Claude Code and Claude Desktop and prints the config for Codex and others.

curl -fsSL https://raw.githubusercontent.com/Neopric-Inc/NeoApps.AI-CodeGenerator/main/install.sh | bash

Then ask your agent to build an app, or use the CLI: neoapps new MyApp --schema schema.sql --ui ui.config.json --deploy. Setup guide ↗
