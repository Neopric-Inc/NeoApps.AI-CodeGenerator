Run it locally

One command to install.

Requires Git, the .NET 10 SDK and Docker. The installer registers the MCP server with Claude Code and Claude Desktop and prints the config for Codex and others.

curl -fsSL https://raw.githubusercontent.com/Neopric-Inc/NeoApps.AI-CodeGenerator/main/install.sh | bash

From a clone of the repository, preview the sample with neoapps preview AuditDesk --schema samples/auditdesk/auditdesk.sql --ui samples/auditdesk/auditdesk.ui.json. Review the plan, then run neoapps new AuditDesk --schema samples/auditdesk/auditdesk.sql --ui samples/auditdesk/auditdesk.ui.json --deploy to generate and run it. Setup guide ↗

Data rules

Business rules are config, not code.

The API enforces them on every query, for people, AI and integrations alike.

Tenancy and row scopes

Customer portals: each customer sees only their own rows.

Lifecycles

Status steps, who may take them, and per-role edit locks.

Validations and numbering

Formats, ranges, date order, totals; INV-2026-00001.

Audit, outbox, limits

Change history, domain events and plan limits.

Migrations keep data

Schema changes become reviewed FluentMigrator migrations.

Background jobs

Long work and approvals on a RabbitMQ worker.

AI workflows

Document Q&A, ask-your-data and AI-drafted records with approval.

Local models

Any OpenAI-compatible endpoint, e.g. Ollama or vLLM.

Signatures

Steps that need the person's password again; signer, time and statement logged.

Notifications

Bell and email from rules: who to tell, when a record moves.

Installable

Every app installs on phones and desktops.

CSV import and export

Any list. Imports are checked against every rule first, then saved all or nothing.
